# Sierra Workarounds Review By Garrett with Fixes

- Global Fixes:
- all indicators have value format that matches decimal places of min tick 
    examples:
    - es min tick is 0.25 so value format is 0.01, 
    - 6e min tick is 0.00005 so value format is 0.00001

## Indicator Calculations

- `atr`
  - SIERRA: First ATR is bar-0 true range, then Wilder smoothing (rma).
  - TRADESTER_INIT: Started from an SMA of the first full window.
  - TRADESTER: Starts from bar-0 true range, then Wilder smoothing (rma).
  - FIX: none needed, just make sure we are using same rma function

- `bb`
  - SIERRA: Uses the study input data. In the bad export, that input was set to `low`.
  - TRADESTER_INIT: Expected BB to use `close`, but Sierra was configured to `low`.
  - TRADESTER: Uses `last`/close input data, expanding middle band, and `0` stdev until full window.
  - FIX: set input data to `last` instead of `low`

- `cumulative`
  - SIERRA: Adds each bar's real high to a running total.
  - TRADESTER_INIT: Added the exported CSV high, which can be rounded.
  - TRADESTER: Uses the high value implied by Sierra's running total.
  - FIX: none needed they both refernce the same data

- `sum`
  - SIERRA: Sums internal tick-precision closes.
  - TRADESTER_INIT: Summed rounded CSV closes.
  - TRADESTER: Rebuilds closes from golden diffs, then rolls the sum.
  - FIX: adjusted value format in sierra to match min tick

- `vwap`
  - SIERRA: Resets at 17:00 ET; the 17:00 bar starts the next session.
  - TRADESTER_INIT: Reset at the wrong session hour.
  - TRADESTER: Resets at 17:00 ET.
  - FIX: ? not sure if fixed...sierra is set to reset at 22:00:00 UTC

- `vwapBands`
  - SIERRA: Bands use stdev of session VWAP values.
  - TRADESTER_INIT: Used price distance from VWAP.
  - TRADESTER: Uses stdev of session VWAP values.
  - FIX: none needed, did switch calculation mode to `vwap variance` instead of `standard deviation` https://www.sierrachart.com/index.php?ID=108&page=doc/StudiesReference.php#StandardDeviationBandCalculation

- `vwma`
  - SIERRA: Uses expanding warmup, float32 graph values, and 2-decimal CSV export.
  - TRADESTER_INIT: Used float64 output.
  - TRADESTER: Uses expanding warmup, float32 graph values, and 2-decimal export.
  - FIX: value format handles the rounding; no specific fix needed.

- `crossabove`
  - SIERRA: Fires when price moves above, including after ties that started below.
  - TRADESTER_INIT: Only handled strict previous-below to current-above crosses.
  - TRADESTER: Handles tie chains; outputs bar low on cross, else `0`.
  - FIX: none needed

- `crossbelow`
  - SIERRA: Fires when price moves below, including after ties that started above.
  - TRADESTER_INIT: Only handled strict previous-above to current-below crosses.
  - TRADESTER: Handles tie chains; outputs bar high on cross, else `0`.
  - FIX: none needed

- `linreg`
  - SIERRA: Warmup repeats the first full-window value rounded to 2 decimals.
  - TRADESTER_INIT: Returned Missing during warmup.
  - TRADESTER: Repeats the first full-window value during warmup.
  - FIX: value format handles the rounding; no specific fix needed.

- `rsi`
  - SIERRA: Uses Cutler RSI, expanding gain/loss averages, and bar 0 = `0`.
  - TRADESTER_INIT: Used Wilder RSI.
  - TRADESTER: Uses Cutler RSI with expanding gain/loss averages.
  - FIX: needed to set sierra to wilders moving average type...we want WILDERS RSI AND NOT CUTLER RSI, wilder===rma function

- `ema`

  - TRADESTER_INIT: Used the final EMA multiplier from bar 0.
  - TRADESTER: Starts from first value and grows the multiplier during warmup.
  - FIX: none needed

- `rma`
